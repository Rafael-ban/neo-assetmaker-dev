### v2.2.0（测试预览版）

> 本版本是底层媒体架构的预览性重构。请在实际素材与目标设备上完成验证后再用于正式交付；项目包的 `epconfig.json` 与设备导出目标保持兼容。

**VapourSynth 渲染架构重构**
- 移除 mpv 预览链路，VapourSynth 成为唯一的视频帧渲染核心；预览和导出使用同一份渲染作业与同一条 `.vpy` 图，避免播放器画面与导出文件不一致。
- 预览改为独立 `vs_worker.exe` 工作进程，通过受限的作业协议和共享内存回传帧数据；帧请求、超时、换代、清理与关闭过程均有明确边界，避免 GUI 线程被媒体处理阻塞。
- 导出仍使用 `VSPipe → x264-7mod → MP4Box/lsmash-muxer`，但与预览共用用户脚本和输出契约；裁剪、旋转、色彩转换、填充和图片循环均在同一图中执行。
- 修复未标注色视频在裁剪后跨越高度阈值时，颜色矩阵会随裁剪框变化的问题；启发式改以原始源高度判断，避免同一素材仅因裁剪尺寸不同而改变导出色彩。

**用户 `.vpy` 脚本与运行时配置**
- 新增内置、全局和项目级用户 `.vpy` 脚本选择机制；脚本通过声明式头部、受控注入变量和输出编号契约接入编辑器，而不是把滤镜名称和图结构硬编码在 Python 管线中。
- 将旧 `vsconfig.json` 的滤镜/图配置迁移为用户可读、可编辑的 `.vpy`；保留一次性旧配置迁移边界，避免升级时丢失已有设置。
- 新增 `config/vs_runtime.json`，仅保存工作进程超时、VapourSynth Core 资源和插件目录等运行时参数；不再把渲染图、滤镜顺序或用户素材参数伪装成 JSON 配置。
- 加强运行时配置与作业协议校验：非法字段不会再使整份配置静默回退；脚本信任范围、路径、输出与插件能力均在执行前校验并提供可定位的错误信息。

**编辑、预览与导出一致性**
- 裁剪改为严格保持目标屏幕宽高比，修复此前自由裁剪后导出被非等比拉伸的问题。
- 支持 1× 至 100× VapourSynth 图缩放预览，用于检查裁剪边界和像素细节，不再使用与导出链路不同的 OpenCV 放大近似。
- 修复视频元数据探测、帧请求在关闭窗口、快速切换素材或请求超时场景下的资源竞态；中文路径下的视频、图片循环和导出路径继续受支持。
- 整理并移除已废弃的双图/旧 `vsconfig`/mpv 兼容实现与无效预览代码，降低后续添加 VapourSynth 插件或用户滤镜时的耦合风险。

**构建、发布与文档**
- GitHub Actions 现在可同时构建 Inno Setup 安装版和绿色免安装 ZIP；发布附件同时包含两种产物及 `SHA256SUMS` 校验文件。
- CI 与 Release 不再启用需要付费许可证的 PyArmor 混淆，避免 GitHub Runner 使用 trial 处理大脚本时以 `out of license` 中断发布；本地 `--obfuscate` 参数继续保留。
- 常规推送 CI 跳过 Inno Setup、绿色压缩包和制品上传，仅保留依赖缓存、cx_Freeze 与 worker 自检；手动构建或发布才执行完整打包，缩短日常构建时间。
- 更新 README、用户手册、VapourSynth 架构说明与项目知识库，补充用户 `.vpy` ABI、worker 协议、输出契约、脚本信任边界及第三方实践的适用范围。

### v2.1.6（测试预览版）

**素材制作编码修复**
- 修复导出视频 90°/270° 旋转被镜像的问题（VapourSynth `std.Transpose` 是反射不是旋转，改用 `Transpose`+`Flip` 匹配预览的 `cv2.rotate`）
- 修复裁剪框为奇数或超出画面时导出直接失败的问题（脚本内按实际尺寸动态夹取并取偶）
- 修复长视频导出偶发卡死的问题（`vspipe`/`x264` 输出流未并发排空，管道缓冲区写满导致死锁）
- 修复图片循环素材完全无法导出的问题（RGB→YUV 转换缺少色彩矩阵参数）
- 旋转角度改为吸附至 0°/90°/180°/270°（导出管道从未真正支持任意角度，此前预览显示的任意角旋转在导出时会静默失效）

**导出与校验修复**
- 循环素材（图片模式）源文件缺失时不再静默跳过，改为导出前报错，避免生成引用不存在的 `loop.mp4` 却提示"导出成功"
- 自定义图标 / 叠加图片处理失败时不再继续导出，避免产出缺文件的素材包
- 修复崩溃恢复功能实际从未生效的问题（自动保存与恢复记录未接线），异常退出后现在可正确检测并恢复
- 加载分辨率 / 过渡 / 叠加类型等字段为非法值的配置文件时，现在会报校验错误，而不是静默回退默认值后仍提示"配置有效"

**USB 与 FIDO2 修复**
- 修复文件管理器多个并发操作驱动同一 USB 连接导致的崩溃（协议客户端补充事务锁）
- 修复批量删除文件时未锁定操作状态，可能与其他 USB 操作并发冲突的问题
- 修复 USB 后台任务结束后未释放，长时间使用后累积泄漏的问题
- 修复素材论坛 FIDO2/WebAuthn 登录注册因适配旧版 API 而必定失败的问题（升级到 fido2 2.x API）

**预览体验修复**
- 修复 mpv 正常退出时被误判为连接失败、弹出错误提示的问题
- 修复高 DPI 显示器下视频预览模糊的问题
- 修复视频预览播放位置计数与实际画面逐渐漂移的问题（改为跟随 mpv 实际播放位置同步）
- 修复预览刚加载、mpv 尚未连接完成时发出的跳转/暂停指令被丢弃的问题

**其他修复**
- 修复断点续传遇服务器忽略 Range 请求（返回完整文件）时导致下载文件损坏的问题
- 修复图片保存失败时仍返回"成功"的问题
- 修复视频帧缓存装饰器导致的内存泄漏
